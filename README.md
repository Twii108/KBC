# 🎮 KBC Quiz Game

A Java-based console application inspired by **Kaun Banega Crorepati (KBC)** featuring multiple quiz categories, difficulty levels, lifelines, countdown timer, leaderboard, and prize tracking using Object-Oriented Programming and multithreading.

---

## 🧠 Overview

KBC Quiz Game is an interactive console application that simulates the popular television quiz show. Players can choose quiz categories and difficulty levels, answer timed questions, use lifelines strategically, and compete for the highest score on the leaderboard.

---

## ✨ Features

### ❓ Quiz System
- Multiple quiz categories
- Difficulty selection (Easy, Medium, Hard)
- Randomized questions
- Prize money progression

### ⏳ Timer
- 30-second countdown for every question
- Automatic game termination on timeout
- Multithreaded timer implementation

### 🎯 Lifelines
- 50-50
- Audience Poll
- Expert Advice

### 🏆 Leaderboard
- Player ranking
- Prize tracking
- Final score display

### 🎮 Gameplay
- Category selection
- Difficulty selection
- Skip questions
- Progressive reward system
